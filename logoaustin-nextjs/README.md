# Logo Austin — Next.js rebuild

Premium, static-first rebuild of [logoaustin.com](https://logoaustin.com/) (Logo In Hours LLC) with Next.js 16 / React 19 / TypeScript. All 62 existing URLs, the approved design, images, portfolio and copy are preserved; the frontend is rebuilt as genuine React Server Components.

## Commands

```bash
npm ci
npm run dev              # local development
npm run build            # Node/standalone build (Hostinger VPS)
npm run build:static     # static export -> out/ (used for the temporary domain)
npm run lint && npm run typecheck
npm run docs             # regenerate docs/*.md inventories from content (+ out/ checks)
npm run migrate          # re-run the WordPress/Elementor content converter (needs the export files)
```

Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_SITE_URL` / `NEXT_PUBLIC_NOINDEX` for the target.

## Where things live

- `src/data/site.ts` — every business fact (phones, address, social, Google listing, pricing); nothing is hardcoded elsewhere.
- `src/data/navigation.ts`, `services.ts`, `reviews.ts`, `portfolio.ts` — menus, money-page metadata, verified reviews, portfolio records.
- `src/content/` — migrated page/post JSON and the image inventory (generated by `scripts/convert-elementor.mjs`).
- `src/components/sections/` — the section/block renderer that turns migrated content into React.
- `docs/` — audit, inventories, keyword map, SEO/structured-data/performance/accessibility reports, deployment, migration checklist, off-page plan, approvals.
- `deploy/` — staging `.htaccess` snippet + PHP form endpoint, VPS Nginx config.

## Editing content

Pages and posts are JSON documents in `src/content`. Edit the text in the JSON (or re-run the converter from an updated WordPress export), then rebuild. Reviews are only added to `src/data/reviews.ts` when verified with a source link.
